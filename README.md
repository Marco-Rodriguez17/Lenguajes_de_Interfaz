## Descripción del repositorio

Este repositorio reúne las prácticas de la materia Lenguajes de Interfaz, realizadas en lenguaje ensamblador x86 utilizando MASM y la biblioteca Irvine32. Cada carpeta contiene el archivo fuente `Main.asm` con comentarios y el encabezado de la práctica correspondiente.
